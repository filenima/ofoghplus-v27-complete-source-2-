# رفع اشکال نسخهٔ دسکتاپ — حسابداری افق پلاس

سند مرجع عیب‌یابی برای پشتیبانی و کاربر پیشرفته. هر ردیف: **علامت → علت → راه‌حل**.

> ابزار داخلی برنامه: منوی **کمک ← تشخیص مشکلات** (یا راست‌کلیک روی آیکن کنار ساعت) بیشتر این موارد را خودکار بررسی می‌کند و گزارش قابل‌کپی می‌دهد. لاگ کامل در `%APPDATA%\OfoghPlus\logs\` است.

## پیش‌نیازهای رسمی هر نسخه

| نسخه | سیستم‌عامل | پیش‌نیازها |
|---|---|---|
| مدرن (`OfoghPlus-Setup-*.exe`) | ویندوز ۱۰ / ۱۱ (۶۴بیتی) | هیچ چیزِ اضافه — VC++ در صورت نیاز هنگام نصب بی‌صدا نصب می‌شود |
| پرتابل (`OfoghPlus-Portable-*.exe`) | ویندوز ۱۰ / ۱۱ | بدون نصب؛ یک فایل |
| Legacy (`OfoghPlus-Legacy-Setup-*-x64.exe` یا `-ia32.exe`) | ویندوز **۷ SP1** / ۸ / ۸.۱ | SP1 + KB4474419 (SHA-2) + KB3126587 + KB3063858 + VC++ 2015-2022 (خودکار نصب می‌شود) |

> ویندوز ۷ بدون SP1 و ویندوز Vista/XP پشتیبانی **نمی‌شوند**.

## کجاها را برای پشتیبانی بفرستم؟

۱. در برنامه: **کمک ← تشخیص مشکلات ← کپی گزارش برای پشتیبانی**
۲. در صفحهٔ خطا: دکمهٔ **کپی اطلاعات خطا برای پشتیبانی**
۳. کل پوشهٔ `%APPDATA%\OfoghPlus\logs` (فایل‌ها چرخشی‌اند: هر کدام حداکثر ۲ مگابایت × ۳ نسخه)

## نکتهٔ آنتی‌ویروس‌ها (برای پشتیبانی)

exe بدون امضای دیجیتال در برخی آنتی‌ویروس‌های ایرانی (کاسپرسکی/نورتون/اویرا و…) false-positive می‌شود. راه‌حل‌های ترتیبی:
۱. به‌روزرسانی تعریف آنتی‌ویروس و اسکن مجدد (اغلب رفع می‌شود)
۲. افزودن استثنا برای پوشهٔ نصب و `%APPDATA%\OfoghPlus`
۳. خرید گواهی Code Signing (OV حدوداً سالانه؛ EV هشدار SmartScreen را کامل حذف می‌کند) و ست‌کردن آن در `desktop/package.json` → `build.win.certificateFile`
