# چک‌لیست پیش از انتشار نسخهٔ دسکتاپ — حسابداری افق پلاس

این چک‌لیست را **قبل از هر انتشار عمومی** کامل اجرا کنید. هر مورد را علامت بزنید.

---

## الف) چک‌لیست ساخت (روی سیستم build)

- [ ] `bash scripts/build-desktop.sh` (یا `build-desktop.ps1`) بدون هیچ خطا تمام شده است
- [ ] هر سه خروجی ساخته شده: `OfoghPlus-Setup-<ver>.exe`، `OfoghPlus-Portable-<ver>.exe`، `OfoghPlus-Legacy-Setup-<ver>-x64.exe` و `-ia32.exe`
- [ ] پیام «موتور Prisma ویندوز: libquery_engine-windows.dll.node — تایید شد» در خروجی build دیده شده (**حیاتی** — بدون آن سرور روی ویندوز بالا نمی‌آید)
- [ ] `SHA256SUMS.txt` ساخته شده و هش فایل‌ها با `certutil -hashfile <فایل> SHA256` مطابقت دارد
- [ ] پچ `binaryTargets = ["native", "windows"]` در `prisma/schema.prisma` هست و `bun install` بعد از آن اجرا شده
- [ ] حجم باندل سرور منطقی است (`desktop/resources/server` — چند صد مگابایت؛ اگر چند کیلوبایت است یعنی بیلد ناقص است)
- [ ] `desktop/resources/node/node.exe` داخل نصاب است (و `node-ia32.exe` برای Legacy)
- [ ] `desktop/resources/redist/VC_redist.x64.exe` و `VC_redist.x86.exe` داخل نصاب است
- [ ] شمارهٔ نسخهٔ `desktop/package.json` و `desktop/legacy/package.json` یکی و درست است
- [ ] فایل Setup روی یک سیستم **بدون** اینترنت انتقال یافته و hش آن سالم است

## ب) تست روی ماشین مجازی تمیز (VM)

برای هر کدام یک VM **تمیز بدون هیچ نصب اضافه** (نه سیستم شخصی خودتان):

- [ ] **ویندوز ۱۱ تمیز**: نصب Setup مدرن → آیکن دسکتاپ → باز شدن splash → صفحهٔ ورود
- [ ] **ویندوز ۱۰ تمیز**: مثل بالا + تست نسخهٔ پرتابل (بدون نصب)
- [ ] **ویندوز ۷ SP1 تمیز ۶۴بیتی** (بدون VC++ از قبل): نصب Setup Legacy → اجرا؛ در طول نصب هیچ پنجرهٔ سیاه/CMD دیده نشود
- [ ] **ویندوز ۷ SP1 تمیز ۳۲بیتی**: نصب `…-ia32.exe` → اجرا
- [ ] **ویندوز ۸.۱**: نصب Legacy → اجرا

## ج) تست‌های عملیاتی (روی هر VM)

- [ ] هیچ پنجرهٔ PowerShell/CMD در نصب و اجرا دیده نمی‌شود
- [ ] splash بلافاصله بعد از دابل‌کلیک ظاهر می‌شود (کمتر از ۲ ثانیه)
- [ ] ورود با `admin / admin1234` انجام می‌شود و **همان روز اول** رمز عوض می‌شود
- [ ] یک فاکتور صادر و ذخیره می‌شود → بستن کامل برنامه (خروج کامل از منوی tray) → اجرای مجدد → فاکتور سر جایش است
- [ ] دابل‌کلیک دوباره روی آیکن هنگام اجرا → پنجرهٔ موجود جلو می‌آید (نه نمونهٔ دوم)
- [ ] بستن پنجره → رفتن به tray → دابل‌کلیک روی آیکن کنار ساعت → برگشت پنجره
- [ ] منوی **کمک ← تشخیص مشکلات** اجرا می‌شود و همهٔ ردیف‌ها «سالم» هستند
- [ ] Task Manager بعد از «خروج کامل»: هیچ پروسهٔ `OfoghPlus` یا `node` باقی نمانده
- [ ] خروج از اینترنت (کابل را بکشید) → برنامه کامل کار می‌کند (نسخهٔ آفلاین است)

## د) تست‌های بدترین حالت

- [ ] **بدون اینترنت هنگام نصب**: نصاب بدون دانلود چیزی کامل نصب می‌کند (همه‌چیز داخل بسته است)
- [ ] **آنتی‌ویروس فعال** (کاسپرسکی/Defender سختی‌گیر): نصب و اجرا؛ در صورت بلاک، مسیر استثنا مستند در `TROUBLESHOOTING-fa.md` جواب می‌دهد
- [ ] **SmartScreen**: پیام ظاهر می‌شود → More info → Run anyway → نصب ادامه می‌کند (مستند شده)
- [ ] **پورت اشغال**: یک برنامهٔ دیگر را روی 3456 تا 3460 بگذارید → برنامه از پورت آزاد بعدی استفاده می‌کند
- [ ] **قطع برق وسط کار**: اجرای مجدد → دیتابیس سالم است (WAL)
- [ ] **حذف و نصب مجدد**: بعد از Uninstall و نصب دوباره، داده‌های `%APPDATA%\OfoghPlus` حفظ شده‌اند

## هـ) انتشار

- [ ] تگ زده شده: `git tag desktop-v<ver> && git push --tags`
- [ ] GitHub Actions سبز شده و هر سه Artifact + SHA256SUMS ساخته شده‌اند
- [ ] Release منتشر شده با جدول فایل‌ها و پیش‌نیازهای ویندوز ۷
- [ ] لینک دانلود به مشتریان داده شده + سند «نصب و شروع» برای کاربر عادی

## اشتباه‌هایی که در گذشته دقیقاً باعث «نصب شد ولی باز نشد» شد (دیگر تکرار نشود)

۱. بیلد بدون `binaryTargets` ویندوز → موتور Prisma ویندوز در باندل نبود → سرور کرش. (الان build چک می‌کند و می‌ایستد)
۲. فایل VC++ redist در مسیری بود که نصاب آن را جست‌وجو می‌کرد نیست. (الان داخل `resources\redist` باندل و بی‌صدا نصب می‌شود + مسیر نجات بدون VC++)
۳. فایل `NODE_VERSION` نوشته نمی‌شد → پالی‌فیل‌های Node 16 فعال نمی‌شد → کرش آنی روی ویندوز ۷. (الان خود برنامه نسخهٔ node را probe می‌کند)
۴. `node-ia32.exe` باندل نمی‌شد → ویندوز ۷ ۳۲بیتی هیچ‌وقت کار نمی‌کرد. (الان در بیلد Legacy هست)
۵. هیچ crash-handler و صفحهٔ خطایی نبود → هر شکست = مرگ بی‌صدا = «هیچ اتفاقی نیفتاد». (الان uncaughtException + صفحهٔ خطای فارسی + تشخیص مشکلات)
